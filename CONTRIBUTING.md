# Contributing to Push Hack

Thanks for your interest in Push Hack. This is a community project and any kind of contribution is very welcome.

This is probably the first file that would require input from people with more expertise in software development. So, if you are *that* kind of person and if you would like to contribute, please join the [Discord Server](https://discord.gg/8y6aYxy9nU) so we can discuss the next steps.
